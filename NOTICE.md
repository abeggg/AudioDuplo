# Origem e atribuição

Esta edição é uma evolução independente do código do projeto **Áudio Duplo V4 QCY**, fornecido pelo proprietário do projeto para adaptação e publicação.

A arquitetura WASAPI, o ring SPSC e o resampler com estado derivam dessa base. As regras específicas de QCY foram removidas; foram adicionados interface, compatibilidade genérica, volume, preferências, diagnóstico, tratamento de recursos, testes e distribuição.

O projeto original foi lido e copiado para uma nova pasta. A edição original e seu executável não fazem parte deste pacote.
