# Segurança

O projeto não coleta telemetria nem recebe conexões de rede. Ainda assim, bugs em processamento de áudio, persistência ou distribuição devem ser tratados com cuidado.

Para suspeita de vulnerabilidade, prefira o recurso **Report a vulnerability** na aba Security do repositório, se habilitado pelo mantenedor. Não inclua dados pessoais, gravações ou segredos em issues públicas. O projeto não oferece prazo garantido de resposta.

Baixe binários dos lançamentos publicados pelo mantenedor e compare o SHA-256 com `SHA256SUMS.txt`. Checksum detecta alteração do arquivo, mas não substitui assinatura digital nem autentica o autor por si só.
